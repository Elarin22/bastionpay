# Surface: 메인(랜딩) 화면 — mode: Persuade (교육용 서비스 소개)

Audience/job: 수강생·강사가 서비스를 이해하고 시작하기로 진입. CTA: 서비스 소개(앵커), 시작하기(/signup).
Content: 히어로(서비스 소개), 주요 기능 3개. 예시 데이터는 "예시 데이터" 표기.

## Direction contract
THESIS: 금융 서비스의 첫 화면에서 "마스킹된 계좌와 불변 원장"을 직접 보여 준다. 아이콘 카드 3열이라는 기본 배열을 거부한다.
OWN-WORLD: 화이트 지면 + 딥 네이비 히어로(지면의 40~50%), 스틸블루 보조색 하나. Pretendard 자체 호스팅, 얇은 헤어라인, 표 형태 원장, tabular-nums. 부산국제영화제식 상단 유틸바 + 가로 내비.
STORY: 방문자는 이것이 실제 금융이 아닌 보안 학습용 서비스임을 알고, 연동·원장·보안 세 축을 이해한 뒤 시작하기를 누른다.
FIRST VIEWPORT: 상단 네이비 유틸바(교육용 고지), 흰 헤더(워드마크·내비·로그인/회원가입). 아래 네이비 히어로: 왼쪽 대형 헤드라인과 시작하기/서비스 소개 버튼, 오른쪽 가상계좌 원장 패널(마스킹 번호, 거래 3행).
FORM: 에디토리얼 행(row) 목록형 기능 소개, 셸프 후보 중 1순위. seed: pinned-by-brief(biff.kr 참조, 색 사용자 확정).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
